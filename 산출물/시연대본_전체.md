## A. 시작 — "처음 쓰는 보호자"

### A1. 로그인 ○ · 15초
- **누르는 곳**: 로그인 화면(SCR-001) → **카카오로 시작하기**
- **보이는 것**: "상담은 녹음만, 정리는 AI가", 음성은 요약 후 자동 삭제된다는 안내
- **멘트**: 카카오로 로그인합니다. 처음 화면부터 음성은 요약 후 자동으로 지워진다고 알려 줍니다.
- 빼려면 이미 로그인한 상태에서 홈부터 시작하면 됩니다.

### A2. 아이 프로필 등록 ○ · 20초
- **누르는 곳**: 아이 프로필 등록(SCR-002) → 별칭 '도윤이', 생년월, 치료 종류 '언어' → **시작하기**
- **보이는 것**: "실명 대신 집에서 부르는 이름" 안내
- **멘트**: 아이 실명은 받지 않고, 집에서 부르는 별칭만 받습니다. 이 별칭은 받아쓰기 정확도를 높이는 힌트로도 쓰입니다.
- 주의: 이미 아이가 등록된 계정이면 이 화면이 뜨지 않습니다. 시연하려면 새 계정이 필요합니다.

## B. 녹음 — "상담 전에 버튼 하나" (시나리오 ①②)

### B1. 홈 화면 ◎ · 20초
- **누르는 곳**: 홈(SCR-003)
- **보이는 것**: 이번 주 숙제 3/5 진행률, 숙제 항목, 최근 회기 카드, 아래 고정된 **녹음하기** 버튼
- **멘트**: 홈에는 이번 주 숙제와 최근 회기가 있고, 아래에 녹음 버튼 하나가 있습니다. 보호자가 할 일은 이 버튼을 누르는 것뿐입니다.

### B2. 녹음 동의와 녹음 ★ · 40초
- **누르는 곳**: **녹음하기** → 녹음 화면(SCR-004) → **선생님께 녹음 동의를 받았어요** 체크 → 녹음 → 10초 뒤 **일시정지** → 재개 → **종료**
- **보이는 것**: 체크 전에는 녹음 버튼이 꺼져 있음, 타이머 mm:ss / 15:00, "녹음 중에는 화면이 꺼지지 않아요"
- **멘트**: 녹음 전에 선생님 동의 체크가 먼저입니다. 체크하지 않으면 녹음 버튼이 켜지지 않고, 서버에도 동의 없는 회기는 저장되지 않습니다. 상담은 최대 15분이고, 녹음 중에는 화면이 꺼지지 않게 막아 둡니다. 아이폰에서 화면이 꺼져 녹음이 끊기던 문제를 2차에 고친 부분입니다.
- 주의: 라이브 녹음 파일은 처리하는 데 1분 넘게 걸립니다. 종료 후 처리 화면은 B3의 업로드 파일로 보여 주고, 이 녹음 회기는 끝까지 기다리지 마세요.

### B3. 파일 올리기 → 처리 중 ◎ · 30초
- **누르는 곳**: 녹음 화면 → **이미 녹음한 파일 올리기** → 준비한 1분 m4a 선택 → 처리 중 화면(SCR-005)
- **보이는 것**: 업로드 ✓ → 받아쓰기 ● → 요약 ○, "보통 1~2분 걸려요. 화면을 닫아도 계속 진행돼요."
- **멘트**: 다른 앱으로 녹음한 파일도 올릴 수 있습니다. 올리면 받아쓰기와 요약이 자동으로 이어지고, 화면을 닫아도 서버에서 계속 처리됩니다.
- 주의: 처리가 끝날 때까지 기다리지 말고, 바로 C로 넘어가 **미리 만든 12/08 회기**를 엽니다.

### B4. 업로드 실패 후 다시 올리기 ○ · 20초
- **누르는 곳**: (미리 비행기 모드로 녹음을 끝내 둔 경우) 녹음 화면의 **보관된 녹음 1개 · 다시 올리기**
- **멘트**: 치료실 와이파이가 끊겨도 녹음은 휴대폰에 보관됐다가 다시 올릴 수 있습니다.
- 준비가 번거로우면 빼세요.

## C. 확인 — "집에 가는 길에 4칸 요약" (시나리오 ③④)

### C1. 회기 상세 · 4칸 요약 ★ · 40초
- **누르는 곳**: 홈 최근 회기 카드 **12/08** → 회기 상세(SCR-006) 요약 탭
- **보이는 것**: "12월 8일 (월) · 8분 6초", 오늘 한 활동(그림 카드 2어절 말하기), 아이 반응('사과 줘' 스스로 4회), 집에서 할 숙제('○○ 줘' 요청, 매일), 다음 목표(2어절 10회)
- **멘트**: 상담이 이렇게 네 칸으로 정리됩니다. 회의록처럼 대화를 줄인 게 아니라, 언어치료 상담 구조에 맞춰 **집에서 할 숙제**를 중심에 놓았습니다. 숙제의 빈도도 따로 뽑습니다. 진단이나 조언처럼 녹음에 없는 판단은 만들지 않습니다.

### C2. 원문과 음성 ◎ · 20초
- **누르는 곳**: **원문** 탭 → 받아쓰기 원문 스크롤 → 음성 재생
- **보이는 것**: 받아쓰기 원문, 재생 바(원본이 지워진 회기는 "원본은 삭제되었습니다")
- **멘트**: 요약이 의심스러우면 원문을 바로 확인할 수 있습니다. 원본 음성은 요약이 끝나면 자동으로 지우는 게 기본값이라, 지워진 회기에는 안내 문구만 나옵니다.
- 주의: 재생을 보여 주려면 자동 삭제를 끈 상태로 만든 회기가 하나 필요합니다.

### C3. 요약 수정 ★ · 30초
- **누르는 곳**: **수정** → 요약 수정(SCR-007) → 숙제 빈도 '매일'을 '하루 두 번'으로 고침 → **저장**
- **보이는 것**: "저장했어요" 토스트, 회기 상세에 '수정됨' 표시
- **멘트**: AI가 틀리면 보호자가 바로 고칩니다. 고친 비율을 지표로 쟀는데, 1차 38%에서 2차 15%로 줄었습니다.

### C4. 회기 타임라인 ○ · 15초
- **누르는 곳**: 하단 탭 **회기** → 회기 타임라인(SCR-008)
- **보이는 것**: 2026년 12월, 12/08·12/04·12/01 카드, 요약 완료/처리 중/실패 배지
- **멘트**: 회기가 쌓이면 아이별 타임라인이 됩니다. 몇 달 동안 무엇을 연습했는지 한 번에 볼 수 있습니다. B3에서 올린 회기도 처리 중으로 보입니다.

## D. 실천 — "숙제 체크와 알림" (시나리오 ⑤)

### D1. 숙제 체크와 진행률 ★ · 30초
- **누르는 곳**: 하단 탭 **숙제** → 숙제 모아보기(SCR-009) → '○○ 줘' 체크
- **보이는 것**: 3/5 → 4/5 진행률, 숙제마다 출처 회기 날짜, 기간 탭(이번 주/지난 주/전체)
- **멘트**: 요약 속 숙제는 그대로 체크리스트가 됩니다. 체크하면 이번 주 진행률이 바로 올라가고, 날짜를 누르면 그 숙제가 나온 상담으로 갑니다.

### D2. 숙제 알림 ◎ · 30초
- **누르는 곳**: 설정(SCR-010) → 숙제 알림 ON, 시각 확인 → (알림 도착 시) 알림 누름
- **보이는 것**: "숙제 알림 (ON) 오후 8:00", 알림 클릭 시 숙제 화면으로 이동
- **멘트**: 매일 정한 시각에 남은 숙제를 알려 줍니다. 1차 테스트에서 '숙제를 자꾸 까먹는다'는 의견이 가장 많아 2차에 추가했고, 숙제 체크율이 46%에서 68%로 올랐습니다.
- 주의: 알림은 30분마다 도는 작업이 보내므로 시연 시각에 정확히 오지 않을 수 있습니다. 미리 받아 둔 알림 화면 캡처로 대체하세요.

- 주의: 실제로 탈퇴하면 시연 계정이 사라집니다. 입력 창까지만 보여 주세요.
