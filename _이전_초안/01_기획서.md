# 말자람 노트 (MalJaram Note) 기획서

> 언어치료 중인 아이의 부모를 위한 **치료 상담 기록 앱**
> 치료 후 듣는 5~10분 상담을 녹음하면, AI가 "오늘 한 활동 / 아이 반응 / 집에서 할 숙제 / 다음 목표"로 정리해 줍니다.

> ⚠️ **가상 데이터 안내**: 이 문서의 인터뷰 대상자, 응답, 수치는 기획 예시를 위해 만든 **가상 데이터**입니다. 실제 인터뷰를 진행한 뒤 교체하세요. 포트폴리오에 실제 결과로 기재하면 안 됩니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026-11-16 ~ 2026-12-27 (6주) |
| 실제 개발 | 3일 (MVP 2.5일 + 피드백 반영 0.5일) |
| 인원 | 1인 (기획·설계·개발·테스트) |
| 형태 | 모바일 웹앱 (PWA) |

## 1. 배경과 문제 정의

### 1.1 배경
- 언어발달 지연 아동은 보통 주 1~2회, 40분 내외의 언어치료를 받습니다.
- 치료가 끝나면 치료사가 보호자와 5~10분 상담을 합니다. 오늘 한 활동, 아이 반응, **집에서 해야 할 연습(숙제)**을 전달하는 시간입니다.
- 치료 효과는 치료실 40분보다 **집에서 보내는 나머지 시간의 반복 연습**에 크게 좌우됩니다.

### 1.2 문제
| # | 문제 | 근거 (가상 인터뷰 5명) |
|---|---|---|
| P1 | 상담 내용을 집에 오면 절반 이상 잊는다 | 5명 중 5명 |
| P2 | 메모하려 해도 아이를 챙기느라 적을 수 없다 | 5명 중 4명 |
| P3 | 상담을 듣지 못한 가족(배우자, 조부모)에게 전달하기 어렵다 | 5명 중 3명 |
| P4 | 숙제를 했는지 안 했는지 스스로도 기억하지 못한다 | 5명 중 3명 |
| P5 | 몇 달 동안 무엇이 달라졌는지 한눈에 보이지 않는다 | 5명 중 2명 |

### 1.3 문제 정의 (한 문장)
> **언어치료 중인 아이의 보호자는 치료 후 상담 내용을 기억하고 실천할 수단이 없어서, 치료실 밖의 연습이 끊기고 있다.**

| ID | 대상 | 아이 | 치료 | 핵심 발언 |
|---|---|---|---|---|
| U1 | 엄마, 30대 후반, 전업 | 남아 4세 | 언어 주 2회 | "선생님 말씀 들을 때는 다 알 것 같은데, 차에 타면 생각이 안 나요." |
| U2 | 아빠, 40대 초반, 맞벌이 | 여아 5세 | 언어 주 1회 | "주말에만 제가 데려가는데, 아내한테 설명하면 '그래서 뭘 하라는 거야?'가 돌아와요." |
| U3 | 엄마, 30대 중반, 맞벌이 | 남아 3세 | 언어+놀이 | "메모 앱에 적다가 아이가 뛰쳐나가서 못 적은 적이 많아요." |
| U4 | 엄마, 40대 초반, 전업 | 남아 6세 | 언어 주 2회 | "숙제를 하긴 하는데 매일 했는지는 솔직히 모르겠어요." |
| U5 | 할머니, 60대 중반 | 여아 4세 | 언어 주 1회 | "딸 대신 데려가는데 들은 걸 전해주기 어려워요. 글씨도 작고." |

**치료사 관점 (가상, 언어재활사 7년 차)**
- "숙제를 내 드려도 다음 회기에 물어보면 '바빠서 못 했어요'가 절반이에요."
- "집에서 아이가 어떻게 말하는지는 부모님 말씀으로만 알 수 있어서 정확하지 않아요."

### 인터뷰에서 얻은 설계 원칙
1. **입력은 녹음 버튼 하나.** 아이를 챙기는 상황에서 타이핑을 요구하면 실패합니다.
2. **결과는 "해야 할 일" 중심.** 대화 요약보다 숙제 체크리스트가 더 가치 있습니다.
3. **녹음은 민감하다.** 치료사 동의와 원본 삭제 옵션이 반드시 있어야 합니다.

## 3. 페르소나 (가상)

**김지현 (38세, 전업주부)**
- 4세 아들이 표현언어 지연으로 주 2회 언어치료 중이고, 둘째(1세)를 데리고 치료실에 다닙니다.
- 목표: 선생님이 말한 집 연습을 빠뜨리지 않고 매일 하는 것
- 불편: 상담 중 둘째가 울면 집중할 수 없어 내용을 놓칩니다.
- 사용 장면: 상담 시작 전 녹음 → 집에 와서 요약 확인 → 저녁에 숙제 체크

## 4. 해결 방안

### 4.1 핵심 흐름
```
[상담 시작 전] 치료사 동의 확인 → 녹음 시작
[상담 종료]   녹음 종료 → 자동 업로드
[약 1분 후]   받아쓰기(STT) → AI 요약(4개 섹션) → 숙제 체크리스트 생성
[집에서]     숙제 체크, 지난 회기 타임라인 확인
```

### 4.2 경쟁/대체재 분석
| 대체재 | 한계 | 말자람 노트의 차별점 |
|---|---|---|
| 휴대폰 메모 앱 | 상담 중 타이핑 불가, 구조 없음 | 녹음만 하면 구조화 |
| 휴대폰 녹음 앱 | 다시 들을 시간이 없음, 검색 불가 | 요약 + 할 일로 변환 |
| 범용 AI 회의록 앱 | 치료 용어·숙제 개념 없음, 아이 단위 누적 없음 | 언어치료 전용 섹션, 아이별 타임라인 |
| 육아 기록 앱 | 수유·수면 중심, 치료 기록 없음 | 치료 회기 중심 |

## 6. 기술 스택

| 영역 | 선택 | 선택 이유 |
|---|---|---|
| Frontend | Next.js 15 (App Router), TypeScript, Tailwind CSS | 웹/서버 코드 한 저장소, PWA 지원 |
| Backend | Next.js Route Handlers | 별도 서버 없이 API Key를 서버 측에 보관 |
| DB/Auth/Storage | Supabase (PostgreSQL, Auth, Storage) | 인증·파일·RLS를 3일 안에 구성 가능 |
| STT | OpenAI Whisper API | 한국어 정확도와 연동 난이도의 균형 (대안: 네이버 CLOVA Speech) |
| 요약 | Claude API (JSON 구조화 출력) | 긴 한국어 대화 요약, 스키마 고정 출력 |
| 배포 | Vercel | Git push 기반 자동 배포 |

### 아키텍처
```
[Browser/PWA] ──녹음 파일──▶ [Supabase Storage (private bucket)]
      │                                   │
      └──POST /api/sessions/{id}/process──▶ [Next.js Route Handler]
                                          ├─▶ Whisper API (STT)
                                          ├─▶ Claude API (요약 JSON)
                                          └─▶ Supabase DB (transcript, summary, homework)
```

## 7. 개인정보·윤리 설계
- **녹음 동의**: "치료사 선생님께 녹음 동의를 받았습니다"에 체크해야 녹음 버튼이 활성화됩니다. 대화 당사자의 녹음은 합법이지만, 신뢰 관계를 위해 동의를 전제로 설계했습니다.
- **원본 최소 보관**: 요약이 끝나면 음성 원본을 자동 삭제하는 것이 기본값입니다.
- **아이 정보 최소화**: 실명 대신 별칭, 생년월일 대신 생년월만 받습니다.
- **접근 통제**: Supabase RLS로 본인 데이터만 조회할 수 있고, Storage는 비공개 버킷과 Signed URL(5분)을 사용합니다.
- **의료 행위 아님**: 요약은 "기록 보조"이며 진단이나 치료 조언을 생성하지 않도록 프롬프트에서 제한합니다.

## 11. 로드맵 (MVP 이후)
1. **가족 공유**: 배우자·조부모 초대, 숙제 체크 공동 관리 (2차 테스트 요청 4건)
2. **아이 발화 기록**: 집에서 아이 말을 녹음해 어휘 수, 평균 발화 길이(MLU) 변화 추적
3. **치료사 리포트**: 회기별 숙제 수행률과 집에서의 변화를 치료사에게 공유
